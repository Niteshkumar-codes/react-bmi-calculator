# react-bmi-calculator
A beginner-friendly BMI Calculator built with React JS using useState hook. It calculates BMI based on user input and displays dynamic results with conditional rendering.
## 🚀 Features

- 📥 User input for height and weight
- ⚡ Real-time BMI calculation
- 📊 Displays BMI result instantly
- 🧠 Conditional messages (Underweight, Normal, Overweight, etc.)
- 🎨 Dynamic UI updates based on BMI result
- ❌ Input validation
